# Gear Forge

Minecraft 1.21.1 / NeoForge 模组。在原版锻造台上给装备做强化、随机词条、宝石镶嵌和转生，另外提供 7 个附魔和 2 个 Curios 饰品。

- Mod ID：`gear_forge`
- 依赖：NeoForge 21.1.228+，[Curios API](https://github.com/TheIllusiveC4/Curios) 9.4+（必需）
- 许可证：MIT（见 [LICENSE](LICENSE)）

## 玩法速览

所有锻造操作在**强化台**（或原版锻造台）完成：装备放第二格（底材），材料放第三格，第一格（模板）按操作需要放材料。

| 材料（第三格） | 操作 | 模板（第一格） |
|---|---|---|
| 锻造锤 | 强化等级 +1（有成功率，失败可能降级/损毁） | 消耗材料（默认钻石，数量随等级增长） |
| 重铸石 | 重新随机词条 | 空或钻石 |
| 红宝石、蓝宝石、绿宝石、黄玉、翡翠、玛瑙、钻石、下界之星 | 镶嵌宝石（每件默认最多 3 颗） | 空 |
| 宝石摘除器 | 摘下最后镶嵌的宝石 | 空 |
| 升阶水晶（底材放宝石） | 宝石阶级 +1（上限默认 5） | 空 |
| 转移宝珠 | 切换副手模式 | 空 |
| 附魔书（装备上需有绿宝石） | 无视冲突写入附魔 | 空 |
| 耀金锭 | 下界合金装备 → 对应耀金装备 | 下界合金升级模板 |
| 耀金铁锤 | 钻石剑 → 钻石弧刀；下界合金剑 → 下界合金弧刀；耀金剑/其它剑 → 耀金弧刀 | 空 |

### 耀金

- **耀金锭**：3 金锭 + 3 钻石无序合成。
- **耀金装备的唯一来源**：锻造台/强化台，模板槽放下界合金升级模板，材料槽放耀金锭，底材放对应的下界合金装备（四件盔甲、剑、镐、斧、锹、锄）。不再有工作台直接合成配方。
- **耀金铁锤**：在强化台（或原版锻造台）对剑使用，锻造成**同材质弧刀**。钻石剑→钻石弧刀、下界合金剑→下界合金弧刀、耀金剑或其它剑→耀金弧刀。弧刀攻击距离 +1、最终攻速 2.0、伤害比同级剑低 1 点，每第 3 次命中会释放一次扇形特效斩击（半径 3.5 格、半角 60°、对周围实体造成 60% 攻击力）。
- **耀金苹果**：4 个耀金锭 + 1 个苹果。营养 6、饱和度 19.2，吸收 I 4 分钟、再生 II 10 秒，并给点金 II 2 分钟。
- **耀金硬币**（饰品）：4 个金锭 + 1 个耀金锭。装备时幸运 +1；同时装备幸运钻石时，幸运钻石的 +20 幸运翻倍为 +40；携带时击杀怪物获得 30 秒点金 I。
- **点金**：I 级挖石头掉 1 个金锭，II 级掉 2 个。耀金苹果、耀金硬币击杀、耀金四件套的点金等级会叠加。
- **金化**：穿齐四件耀金盔甲时获得，猪灵会把玩家视为穿着金装（不再主动仇恨）。
- **外观**：耀金按明暗做「暗部金 → 亮部浅蓝」的色阶；护甲图标左右镜像，实体层沿用原版金套骨架（形状正确、左右对称）、套同一套暗金→浅蓝色阶，穿在身上是金甲透浅蓝，不再有暗紫灰/橙边。

合成表已接入 **JEI**：强化台/锻造台的配方与耀金升级路径都能在 JEI 中查询。JEI 是可选依赖，未安装时模组正常工作（开发客户端默认不带 JEI，需自行安装才能在开发环境中看到 JEI 界面）。

强化台用 1 个原版锻造台 + 3 个铁锭 + 6 块木板合成，外观是下半部分换色的锻造台。

数值平衡在 `config/gear_forge/` 下的四个 JSON 文件里调整（`affixes.json`、`gems.json`、`upgrades.json`、`mob_gear.json`），首次启动时自动生成。强化成功率、降级、损毁、材料消耗都在 `upgrades.json` 里，默认 0→5 级必成，6→15 级成功率从 75% 降到 30%。

## 开发

```bash
./gradlew build          # 构建，产物在 build/libs/
./gradlew runClient      # 启动开发客户端
./gradlew runData        # 重新生成 src/generated/resources
```

完整的环境搭建、测试和发布流程见 [docs/development.md](docs/development.md)。
