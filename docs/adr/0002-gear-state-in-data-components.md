# 装备状态存在数据组件里，只存 id 和数值，含义运行时查配置

强化等级、词条、宝石、转生保留奖励等都注册成 `gear_forge:*` 数据组件，跟着物品走，原版负责存档和网络同步。组件里只记录词条/宝石的字符串 id 和数值，名称、类型、宝石效果在运行时按 id 查配置，这样调平衡不需要迁移存档。

## Consequences

- 组件名和 id 一旦发布就是存档格式，改名需要写数据修复，否则玩家装备上的数据会丢。
- 改配置会直接改变所有已有装备的效果。从配置里删掉一个词条或宝石 id，带它的装备会静默失去这部分效果，提示文本显示原始 id。
- 服务端和客户端如果配置不同，同一件装备在两边的含义不同（GF-007）。
- 转生保留奖励用 id 前缀区分来源（`upgrade_`、`gem_`），结算代码要按前缀去查。
