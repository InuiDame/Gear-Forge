# 平衡数值放在 config/gear_forge 下的自定义 JSON 文件里

词条池、宝石、强化和强化怪物的数值放在四个 Gson 读写的 JSON 文件中，而不是 NeoForge 的 `ModConfigSpec`（TOML，不支持对象列表）或数据包注册表（需要更多代码，按世界生效）。加载时把文件和代码里的默认值合并：补上新字段，带 `id` 的数组按 id 合并，然后写回文件，原文件备份为 `.old`。

## Consequences

- 配置按实例生效，不随世界走，也不会从服务端同步到客户端。客户端的提示文本和锻造预览用的是本地文件（GF-007）。
- 每次启动都会重写配置文件，用户手写的顺序和格式不会保留。
- 目前合并逻辑对不带 `id` 的数组（数值范围、插槽类型、里程碑等级等）直接用默认值覆盖，用户对这些字段的修改每次启动都会丢（GF-003）。
- 没有游戏内重载命令，改完需要重启。
