# GF-005 箭矢附魔的实现和描述不符

- 优先级：P1
- 状态：待修复
- 相关：`event/ModEnchantmentEvents.java`

## 问题

NeoForge 1.21.1 的 `LivingEntity.hurt` 先触发 `LivingIncomingDamageEvent`，后检查受击无敌时间。在这个事件里再调用 `victim.hurt(...)` 会先结算嵌套伤害、设置无敌时间，外层的箭伤只能打出“超过嵌套伤害的那部分”。

1. **霜冻箭**（第 136 行）：在事件里额外 `hurt(magic, 0.5×等级)`，结果箭伤被扣掉同样的数值，净效果约等于没有额外伤害。描述里的“持续受损”也没有实现，只有一次性伤害。
2. **破甲箭**（第 153 行）：用 `genericKill()` 造成额外伤害。这是 `/kill` 用的伤害类型，无视无敌状态（包括创造模式）和图腾判定；同样受嵌套伤害问题影响，额外伤害基本被抵消。
3. **闪电箭 +10%/级**（第 125 行）：条件要求伤害的直接来源是箭，同时伤害类型是闪电。闪电伤害没有直接来源实体，这个分支永远不会执行。
4. **爆炸箭额外伤害**（第 142 行）：注释写“额外伤害”，代码是 `setAmount(5 + 2×(等级-1))`，直接覆盖原箭伤，满蓄力的高伤弓反而变弱。爆炸本身也会先伤到目标并触发无敌时间。
5. **判断用的是手持武器**（第 40 行 `getWeapon`）：箭飞行途中换手，附魔按新手持物计算。`AbstractArrow.getWeaponItem()` 记录了射出时的武器。

## 修复方案

1. 武器统一用 `GearEventHandlers.resolveLauncher(arrow, shooter)`（优先 `getWeaponItem()`，没有时退回手持）。
2. 霜冻：额外伤害直接加到 `event.setAmount(event.getAmount() + 0.5f × 等级)`；如果要“持续受损”，给目标加自定义效果或凋零/中毒，由作者定。
3. 破甲：用 `event.addReductionModifier(DamageContainer.Reduction.ARMOR, (c, r) -> r × (1 - 0.05 × 等级))` 按比例削减护甲减免，不再造成第二次伤害。
4. 闪电：召唤闪电时记录（目标 UUID、等级、过期 tick），在闪电伤害事件里查表放大；或者不召唤会伤人的闪电，改为 `setVisualOnly(true)` 并直接在箭伤里加闪电伤害。
5. 爆炸箭：改成在原伤害上加，`event.setAmount(event.getAmount() + 5 + 2×(等级-1))`；爆炸改用不伤害目标本体的方式，或在箭命中实体时不再额外爆炸。

## 验收标准

用 GameTest 或手动测试，对同一目标、同一弓的箭伤对比：

- 霜冻 V 的伤害 = 普通箭伤 + 2.5。
- 破甲 V 对 20 护甲目标的伤害高于无附魔，对 0 护甲目标相同；创造模式玩家不受伤。
- 闪电 V 的闪电伤害比无附魔高 50%。
- 射出后换手，附魔效果不变。
