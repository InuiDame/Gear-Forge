# GF-014 木棍被当作装备

- 优先级：P2
- 状态：已修复：`GearHelper.isGearItem` 移除 `Items.STICK` 分支，只认有耐久的物品与弓弩/三叉戟/盾牌。
- 相关：`util/GearHelper.java:201`

## 问题

`GearHelper.isGearItem` 显式把 `Items.STICK` 算作装备，所以木棍可以强化、重铸、镶嵌、转生。整理前这还能配合“整组底材全部被改写”刷物品；整理后结果只有 1 个，不再能复制，但木棍仍然是一个零成本、可堆叠到 64 的“装备”：

- 强化/词条的属性修饰符挂在主手，木棍拿在手里就能获得攻击、护甲、生命等加成。
- `docs/idea.md` 提到过“用毒马铃薯当弹药的法杖”，木棍可能是为法杖预留的。

## 修复方案

- 如果没有法杖计划：从 `isGearItem` 删除木棍。已经被锻造过的木棍保留数据组件，但不再能继续锻造，属性仍然生效（可以另外决定是否忽略）。
- 如果有法杖计划：新建法杖物品（不可堆叠、有耐久），用它替代木棍，再删除木棍特例。

## 验收标准

木棍放进锻造台底材格时，所有材料都不产生结果。
